# nexplaystudios.com

The NexPlay Studios website, served by GitHub Pages at https://nexplaystudios.com

- `index.html`: studio page. Use https://nexplaystudios.com as the **developer website** in every Play Console store listing.
- `app-ads.txt`: lists Google AdMob as an authorised seller. AdMob looks for it at the root of the developer website.
- `<game>/privacy.html`: one privacy policy per game. The source copy lives in each game's repo under `legal/privacy.html`.
